# SITIO PV Operations

Centro interno Streamlit para SITIO BioMedical Solutions.

## Demo
```bash
pip install -r requirements.txt
streamlit run app.py
```

Esta versión usa datos ficticios. No introducir datos reales de pacientes.

## Separación
Este repositorio es distinto del portal cliente. Contiene Command Center, Project Factory, información interna, tareas y entregables. Debe desplegarse con autenticación exclusiva para personal SITIO.
